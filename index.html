Questions

Does Aura upload my photos anywhere?

No. The only network requests Aura makes are an update check against our release feed and, if you buy Pro, the Stripe checkout page in your browser. Your files, names and thumbnails never leave your machine. See the privacy policy.

Windows says "Windows protected your PC". Is that normal?

Yes, for now. The installer is not yet signed with a paid code-signing certificate, so SmartScreen shows that warning for a new publisher. Click More info, then Run anyway. You can verify the download came from our GitHub releases.

Which Linux download should I pick?

The AppImage. It runs on any distribution and updates itself. The .deb integrates with apt on Debian and Ubuntu but does not auto-update.

Is there a Mac version?

Not yet. macOS is planned once notarization is in place. Windows and Linux are supported today.

What if I delete something by mistake?

Turn on the recycle folder in Settings before cleaning and removed files are kept for 14 days. Aura never deletes the last copy in a group. Keep your own backups regardless.
